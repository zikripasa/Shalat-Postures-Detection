- Near-duplicates (perceptual hash) and same-session/same-video images were linked into **29 independent groups** for the 40 labeled instances (largest group: 6 instances).
- Cross-source duplicates exist: a web (Labelbox) image is a frame of the same video as two 'SittingMo' frames, and another web image is byte-for-byte the same frame as `qiam(24).jpg` (pHash distance 0).

## Shortcut-learning risk

Capture source is confounded with class: sitting images come almost entirely from the authors' own captures (lab room, two videos), while standing and prostration come mostly from web images. A pixel model can score well by recognising the *source* instead of the *posture*. Group-aware evaluation and pose-based (background-free) features are the mitigations used here.

## Recommendations

1. Treat every metric from this sample as a **high-variance estimate** (29 independent groups). Report confidence intervals.
2. Prefer methods with strong priors (pretrained pose estimation, frozen ImageNet embeddings) over end-to-end fine-tuning.
3. Model **four visual postures**; derive the six prayer phases from temporal order, and label that inference as such.
4. Obtain the full dataset (Kaggle) and, ideally, real prayer videos with phase-level timestamps before any deployment claim.
