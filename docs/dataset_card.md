# Dataset card — Salat Postures Dataset (provided sample)

Full audit with every issue listed: [`artifacts/reports/dataset_audit.md`](../artifacts/reports/dataset_audit.md)
(generated by `scripts/audit_dataset.py`; notebook `01_dataset_audit.ipynb`).

## Provenance

* **Source:** `Salat-Postures-Dataset-main.zip` = the GitHub repository *riotu-lab/Salat-Postures-Dataset*, which contains
  only the folder `Sample-images-with-annotations`. Its README states that the full dataset (1,904 images, 2,156
  instances) is hosted on Kaggle; that release was not part of the provided files and could not be downloaded in the
  authoring environment.
* **Collection (per the dataset README):** photos of students and laboratory members captured with mobile phones from
  various angles and lighting, complemented with images and video frames of people in prayer collected from the
  Internet; labelled with bounding boxes in Pascal VOC format.
* **Citation:** Koubâa et al. (2020), *Activity Monitoring of Islamic Prayer (Salat) Postures using Deep Learning*, CDMA,
  pp. 106–111, IEEE, arXiv:1911.04102.
* **Licence:** no licence file is included in the archive; reuse terms could not be verified. Images are used for
  research/education only and are not redistributed in this repository.

## Known issues and risks

* **Leakage:** a web (Labelbox) image is the same video frame as `qiam(24).jpg` (pHash distance 0); another web image
  is a frame of the same video as `SittingMo58/85`; `qiam(262)` and `sujud77` come from one instructional video; nine
  images share one lab room and participant. These are grouped (pHash ≤ 18 + manual review in
  `configs/session_groups.yaml`) and never cross a train/test boundary.
* **Shortcut risk:** sitting comes almost entirely from the authors' own captures, standing/prostration mostly from web
  images — capture source is confounded with class.
* **Label quality:** one bowing example is a cartoon infographic; the unannotated file `sujud31.jpg` actually shows
  bowing (file names are not labels and are never used as labels).
* **Bias/coverage:** adult men dominate; few viewpoints per class; no women/children-specific coverage was verified;
  Indonesian prayer settings are not represented.

## Privacy

Faces are visible. Every derived artefact that shows a person (figures, demo clip, screenshots) blurs faces.
